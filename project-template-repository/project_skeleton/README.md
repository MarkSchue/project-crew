# Project skeleton

This is the canonical, template-version-pinned skeleton for a new active
project (masterplan section 7.2/7.3). `mas project init` copies this
directory into a new `active-project-repo` and writes a `template.lock`
recording the exact template version and content hash it was generated
from.

Generated placeholder files (`.gitkeep`) mark directories that are empty
until the project produces content. Do not hand-edit `index.md` files —
they are projections regenerated by `mas index rebuild`.
