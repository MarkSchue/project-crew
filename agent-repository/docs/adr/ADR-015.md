# ADR-015: Workflow definition split

- **Decision owner:** project_architect
- **Decision date:** 2026-08-24
- **Status:** accepted
- **Scope:** Contract between Python Flow code, workflow catalog metadata,
  and project-template workflow YAML.

## Options considered

1. Three-artifact contract: Python implementation
   (`agent_platform/execution_plane/flows/<flow>.py`), a registry entry
   (`agent-repository/registry/workflows/<id>/<version>.yaml`) binding
   implementation to state schema and supported execution modes, and a
   project-method template (`project-template-repository/workflows/<id>/
   <version>.yaml`), with compiler-enforced compatibility checks (selected,
   plan section 19.4).
2. A single YAML workflow file that also embeds executable logic
   (no separate Python module).

## Decision drivers

- Plan section 17.1 flags "workflow definition is underspecified" as a
  critical finding.
- Need independently versionable layers: code, capability/registry
  metadata, and project-facing template, each with different release
  cadences.

## Selected option

Adopt the exact three-artifact contract and registry entry shape from
plan section 19.4, including `compatible_platform` and
`supported_execution_modes` fields, with compiler checks proving all
three versions are compatible before a manifest is issued.

## Rejected options and reason

- Option 2: mixes code and configuration in one artifact, breaking the
  separation needed for independent versioning and for keeping project
  artifacts free of executable logic (masterplan principle 13).

## Security and compliance impact

None directly; enables safer workflow evolution by making incompatible
combinations a compile-time error rather than a runtime surprise.

## Operational impact

Requires the SPOC compiler (M3.2) to resolve and validate all three
workflow artifact versions before compiling a manifest.

## Cost impact category

None.

## Portability impact

High (positive) — the project-template workflow YAML is
implementation-agnostic and portable across platform versions within the
declared compatibility range.

## Revisit trigger

None anticipated.
