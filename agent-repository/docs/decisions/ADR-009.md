# ADR-009: Require human approval for consequential actions

- **Decision owner:** project_architect
- **Decision date:** 2026-08-24
- **Status:** accepted
- **Scope:** Approval as a first-class Flow state, not a chat convention.

## Options considered

1. Approval is a durable Flow state (`waiting_for_human`) with a typed
   `ApprovalRequest`/`ApprovalGateway` port, resolved through the API/CLI,
   never through free-form chat (selected, masterplan section 10.3,
   principle 9).
2. Approval represented as an agent asking a question in conversation and
   waiting for a reply in the same session.
3. No built-in approval concept; approval implemented ad hoc per workflow.

## Decision drivers

- "Human approval is a first-class workflow state, not a chat convention"
  is a stated architectural principle (masterplan principle 9).
- Consequential actions list is explicit in the inception decisions
  (`DEC-INCEPTION-001`).
- Approvals must be auditable, resumable, and not silently bypassable.

## Selected option

The SPOC state machine includes `waiting_for_human` as an explicit state
(masterplan section 10.3); an `ApprovalGateway` port persists approval
requests, scope, subject, expiry, and segregation-of-duties rules (plan
section 17.3 change map for M5.2). A run pauses and resumes exactly at
this state; approval or rejection is recorded as a structured event.

## Rejected options and reason

- Option 2: not durable across process restarts, not auditable in the same
  structured way, and easy to conflate with normal agent output.
- Option 3: would produce inconsistent approval semantics per workflow,
  undermining the uniform quality/security gates required by masterplan
  section 29.

## Security and compliance impact

Directly implements the mandatory-approval list in `DEC-INCEPTION-001`;
approvals are versioned, scoped, and time-bound, with stale-approval
invalidation (plan section 17.3, M5.2).

## Operational impact

Requires the `waiting_for_human` -> `running` transition to be resumable
after arbitrary downtime (plan M3.6).

## Cost impact category

None.

## Portability impact

None — `ApprovalGateway` is an application port; the concrete UI/CLI
surface can change independently.
